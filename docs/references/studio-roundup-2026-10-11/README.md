# Design references

Three layout concepts generated with an image model on 11 October 2026 to explore the studio layout. **A (Atlas Studio)** was chosen and is the basis of the current interface: example library on the left, code above the canvas in the centre, parameters on the right and a small floating dock.

The images are design references only. Their drawings, helper names, slider ranges and "check result" button are illustrative and do not describe implemented features. `prompts.txt` contains the prompts used.

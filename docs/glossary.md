# Kaplum Studio

Kaplum Studio ist die Lernumgebung für das Entdecken, Verändern und Erstellen von Turtle-Beispielen.

## Language

**Kaplum Studio**:
Der Name der gemeinsamen Lernanwendung mit visueller Beispielübersicht und einer Arbeitsansicht für Code und Ergebnis.
_Avoid_: Turtle Playground als Name der gesamten Anwendung

**Lehrbeispiel**:
Ein vorbereitetes Zeichen- oder Animationsprogramm, das einen Programmierbegriff oder eine Gestaltungsmöglichkeit demonstriert.
_Avoid_: Schülerprojekt für vorbereitete Beispiele des Lehrenden

**Erkundung**:
Der freie Lernweg, bei dem Lernende vorbereitete Beispiele selbst auswählen, untersuchen und verändern.
_Avoid_: Kurs für die freie Beispielauswahl

**Kurs**:
Eine geordnete Folge von Lektionen, die Programmierbegriffe anhand zusammenhängender Beispiele vermittelt.
_Avoid_: Galerie für die geordnete Lernfolge

**Lektion**:
Eine Einheit innerhalb eines Kurses, die ein bestimmtes Lernziel anhand von Erklärungen und Beispielen vermittelt.
_Avoid_: Lehrbeispiel für eine gesamte Lerneinheit

**Aufgabe**:
Ein eigener Versuch mit einem konkreten Lernziel, beispielsweise ein vorgegebenes Zielbild zu erzeugen.
_Avoid_: Lehrbeispiel für den eigenen Lösungsversuch

**Zielbild**:
Die sichtbare Darstellung des Ergebnisses, das eine Aufgabe verlangt.
_Avoid_: Lösung für das Bild allein

**Musterlösung**:
Ein vorbereitetes Programm, das eine mögliche Erfüllung einer Aufgabe zeigt; andere Programme können ebenfalls richtig sein.
_Avoid_: einzig richtige Lösung

**Lösungstresor**:
Die bewusst geschlossene Ansicht für Musterlösungscode, die Lernende mit einem ausgegebenen Lösungscode öffnen können.
_Avoid_: sicherer Zugriffsschutz

**Lösungscode**:
Ein vom Lehrenden ausgegebener Zahlencode, der die Musterlösungen einer Kursstufe und aller vorherigen Stufen zugänglich macht.
_Avoid_: Passwort für ein Benutzerkonto

**Entwurf**:
Die veränderbare eigene Fassung eines persönlichen Programms, Lehrbeispiels oder Aufgabenversuchs.
_Avoid_: Musterlösung für die Arbeit eines Lernenden

**Kursstufe**:
Eine geordnete Gruppe von Lektionen innerhalb des Kurses; ihr Lösungscode öffnet auch die Musterlösungen aller vorherigen Stufen.
_Avoid_: Lektion für eine gesamte Kursstufe

**Persönliches Projekt**:
Ein benanntes eigenes Programm, das Lernende unabhängig von vorbereiteten Beispielen und Aufgaben weiterentwickeln und wieder öffnen können.
_Avoid_: Datei für ein Projekt, solange kein Datei-Export vorliegt

**Projektfunktion**:
Eine vorbereitete Hilfsfunktion, die Lernende bewusst für ihr Projekt auswählen, zusätzlich zu den verfügbaren Turtle-Grundbefehlen.
_Avoid_: Modulimport für die Auswahl über die Oberfläche

**Projektpaket**:
Ein zusammengehöriges exportiertes Projekt mit Startseite, eigenem Programm und benötigten Bibliotheksbestandteilen, das nach dem Entpacken geöffnet werden kann.
_Avoid_: Einzeldatei für das vollständige Paket
